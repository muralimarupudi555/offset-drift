# Captured output

Generated by `tools/capture_cli.py`, which runs the real command against a real scan against a real PostgreSQL and records what came back. Regenerated by `make bench`; the drift counts are deterministic and only the timing moves.

## An offset scan while rows are being deleted above the cursor

```console
$ offset-drift --write-mode delete --rows 4000
offset pagination, 4000 rows, pages of 50, writer delete 5 per page

reading                             measured     model
------------------------------------------------------
pages fetched                             73        73
rows owed a sighting                    3635
returned more than once                    0         0
never returned at all                    330       330
new rows the reader saw                    0         0
rows the database read                138750

330 rows were present when the scan started, present when it finished, and never returned by any page: 9.1% of the table.
Every page came back full and no query failed.
$ echo $?
4
```

## An offset scan while rows are being inserted above the cursor

```console
$ offset-drift --write-mode insert --rows 4000
offset pagination, 4000 rows, pages of 50, writer insert 5 per page

reading                             measured     model
------------------------------------------------------
pages fetched                             89        89
rows owed a sighting                    4000
returned more than once                  440       440
never returned at all                      0         0
new rows the reader saw                    0         0
rows the database read                204750

440 rows were returned more than once, because the writer moved 5 rows past the cursor between pages.
The reader saw none of the rows inserted during the scan: the cursor counts forward faster than the writer pushes rows down.
$ echo $?
1
```

## A scan that cannot show the effect

```console
$ offset-drift --write-mode insert --writes-per-page 0
invalid scenario: write_mode 'insert' with no writes per page is the quiet table in disguise, and would report a clean scan as though concurrency had been tested
$ echo $?
2
```
